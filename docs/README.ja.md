# mdFOAM Droplet Viewer

mdFOAMの液滴データを、ブラウザ・JSON CLI・MCPから解析できるローカルアプリです。物質・基板・研究室固有のフィールド名を前提にせず、利用者独自のモデルを追加できます。

## 起動と試用

Python 3.10以上を用意し、リポジトリを取得してください。Windowsでは `run.bat` で環境作成と起動ができます。手動の場合は仮想環境内で次を実行します。

```sh
python -m pip install ".[mcp]"
mdfoam-droplet-viewer
python -m mdfoam_droplet_viewer.demo demo-data
```

ブラウザで `http://127.0.0.1:8765` を開き、`demo-data` の絶対パスを入力して **Scan** を押します。**All settings (JSON, SI)** に生成された `settings.json` を貼り、**Apply JSON** → **Analyze** と進めます。右上の **日本語** で主要な画面項目を日本語にできます。

サンプルは架空の物質・合成データです。実研究の結果・論文図・接続先は含みません。

## 自分のデータを解析する

1. ケースまたはケース群の親フォルダを読み込み、System informationでフィールド・次元・分子種・ゾーンを確認します。
2. 相判定用の密度場、必要に応じて数密度・温度場を指定します。候補が複数なら明示的に選択してください。
3. 液相下限と気相上限を密度場の単位で指定します。分子質量はデータから読むかkgで指定します。不明値を水として補完しません。
4. 必要なゾーンを指定します。`solid` などの名前だけでは自動除外しません。未選択は全セルです。
5. 基板から液滴側へ向かう法線を ±X／±Y／±Z から選びます。基板位置を手入力する場合は、元の座標軸の値をmで指定します。
6. **Analyze** で解析し、一覧・ケース別の数値・断面・2Dフィット・3Dを確認します。

水のプリセットは任意に選ぶ参考値です。温度・分子モデルに対してしきい値が妥当か確認してください。全設定のJSONから時刻範囲・間引き・フィット範囲・温度平均なども変更できます。

## 自由な式とPython拡張

**Models & fit** では `a*exp(-k*x)` のような式を入力し、x/yに使う解析量、パラメータの初期値・上下限を指定して登録できます。**Fit selected case** で区間を指定した最小二乗フィットを実行し、推定値・RMSE・R²・点数・収束状態を確認します。

モデルの入力はSI単位です。単位ラベルを変えても数値は換算されません。接触角は度、規格化量は無次元です。観測値の非有限値は除外し、定義域外・点数不足・未収束は理由を返します。

既存研究の固定蒸発式やKelvin理論、水物性の相関式は同梱していません。複雑な数値モデルは `examples/model-plugin` を基に `predict(x, parameters, context)` を実装して追加します。[拡張仕様](EXTENSIONS.md)を参照してください。

## AI・自動処理

```sh
mdfoam-droplet schema
mdfoam-droplet analyze demo-data --settings demo-data/settings.json --save demo
python examples/ai_workflow.py workflow-output
```

CLIは標準出力にJSON、標準エラーに進捗を返します。MCP対応AIには `mdfoam-droplet-mcp` をstdioサーバーとして登録します。解析開始後は `job_id` を使って状態を取得でき、停止もできます。MCPは1プロセスにつき1つのデータ群と解析ジョブを持ちます。

AIはスキーマ取得→ケース検出→情報確認→条件検証→解析→モデル登録→フィット→図出力まで、GUIなしで実行できます。[AI操作ガイド](AI.md)に操作一覧と入出力をまとめています。

## 保存・SSH・制約

解析・モデル定義・フィット曲線は名前を付けて保存できます。保存結果を複数選ぶと重ねて比較できます。CSV ZIP・PNG・GIFも出力できます。保存データには元データのパスが入るため、共有時には内容を確認してください。

SSHは既存のSSH設定・known_hostsを利用し、再構成済みのメッシュと必要な場を取得します。新しい接続先は先に通常のSSHでホスト鍵を登録してください。認証情報は保存しません。ローカルの `processor*` データは対応しています。

対応はASCII OpenFOAM形式です。体積は指定範囲の液相セルの総和、接触角は球フィット、圧力は理想気体近似です。複数液滴の個別追跡・曲面基板・任意の斜め法線・別MD形式には未対応です。可視化は基板に沿った座標を使い、法線方向が表示上のzになります。

保存場所は `~/.mdfoam_droplet_viewer`。環境変数 `MDFOAM_DROPLET_CACHE`、CLIの `--root`、MCPの `--root` で変更できます。旧Private版の保存形式は読み込みません。
